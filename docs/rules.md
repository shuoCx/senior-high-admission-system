# 录取规则清单

**简化广州中考公办高中录取模拟系统 · v2.0**

项目组（8 人）· 组长：陈晓烁 · 2026 年 11 月 19 日

---

## 一、文档定位与使用方式

本清单是全组规则的唯一权威文档：把任务书与设计讨论提示中的录取规则逐条编号条目化。任务书原文为最终依据；本清单与任务书冲突时，以任务书为准并立即修订本清单。

- **编号引用**：后端代码注释、人工推演表头、自动化测试命名均引用规则编号，如 test_R_E04_同分序号排序()——编号是全组共同语言。
- **条目结构**：每条含编号（R-组别##）、条文（一句话描述）、出处（任务书章节）与边界备注（易错点）。
- **状态机制**：全部条目为"已定稿"；新增歧义点先标 OPEN 待组长裁决，裁决后转正并记录。
- **变更流程**：规则修订走 PR，提交说明必须引用条目编号；FAQ（判例库）单独成文件，不混入本清单。

## 三、规则条目（共 73 条）

### R-A 范围与简化（7 条）

| 编号 | 条文 | 出处/边界 |
|---|---|---|
| R-A01 | 全部考生视为具有公办高中报考资格，不区分户籍、随迁子女、应往届及完整学籍年限 | §二 |
| R-A02 | 不区分区内、区外及跨区生；不设区外生比例，统招计划默认全体考生可填报 | §二 |
| R-A03 | 不考虑政策加分、同等条件优先录取和参考科目等级；中考总分＝投档分 | §二 |
| R-A04 | 仅模拟公办普通高中，不含民办、中职、综合高中、港澳班及中外合作项目 | §二 |
| R-A05 | 不模拟退档、放弃录取、报到注册与正式补录 | §二 |
| R-A06 | 只有第三批招生高中有第一批（自招）与第二批（名额分配）；第四批高中仅在第四批招生 | §二＋提示 |
| R-A07 | 不建设真实报名系统；自招资格与考核排名直接输入 | §二 |

### R-B 参数与梯度（8 条）

| 编号 | 条文 | 出处/边界 |
|---|---|---|
| R-B01 | 全市公办高中最低控制线 L 人工设置（示例 492），投档前确定；不得把学校最低录取分预先写入录取条件 | §三.1 |
| R-B02 | 第一梯度线 G₁：小数据直接设置；选做按全体考生前 10% 生成，须说明取整与边界同分处理 | §三.1 |
| R-B03 | 梯度间隔 Δ 默认 40；梯度线序列 G₁、G₁−Δ、G₁−2Δ……最后一档截至 L | §三.1｜例：712/672/632/592/552/512，末档截至 492 |
| R-B04 | 第一梯度 总分≥G₁；第二梯度 G₁−Δ≤总分＜G₁；依次类推；最后一档截至 L | §三.1 |
| R-B05 | 分数恰等于某梯度线 → 归入该线对应的较高梯度 | §三.1｜672 属第二梯度不属第三 |
| R-B06 | 恰等于 L 可参与第二至四批投档；低于 L 不参与任何批次录取 | §三.1｜第一批例外见 R-F02 |
| R-B07 | 自主招生、名额分配可另设计划控制线，且不得低于 L | §三.1 |
| R-B08 | 学校实际录取最低分是投档后的输出结果，不是输入条件 | §三.1 |

### R-C 计划切分与结构（7 条）

| 编号 | 条文 | 出处/边界 |
|---|---|---|
| R-C01 | 总计划 → 先切自招 10% → 再切名额分配＝总计划×50% → 余为第三批统招 | §二｜名额分配按总计划 50% 算，非扣除自招后；例 400→40/200/160 |
| R-C02 | 为简化不设补录 | §二 |
| R-C03 | 同一高中可有多个批次计划；每所高中只在第三或第四批之一设置统招接收计划 | §三 |
| R-C04 | 第一批计划表冗余列：[高中序号, 初始计划数, 已录取数, 计划余额] | 提示文件 |
| R-C05 | 第二批计划表冗余列（高中×初中）：[高中序号, 初中序号, 初始计划数, 已录取数, 计划余额] | 提示文件 |
| R-C06 | 第三批计划表冗余列：[初始计划数, 转入数, 已录取数, 计划余额] | 提示文件 |
| R-C07 | 第四批计划表冗余列：[初始计划数, 计划余额]，不设已录取数列 | 提示文件｜裁决 #2：照抄不补齐 |

### R-D 志愿约束（4 条）

| 编号 | 条文 | 出处/边界 |
|---|---|---|
| R-D01 | 志愿上限：第一批 1 个、第二批 3 个、第三批 6 个、第四批 6 个 | §三 |
| R-D02 | 志愿指向具体计划（批次＋目标高中）；第二批投档时自动关联考生所属初中的名额 | §四.1 |
| R-D03 | 同一考生同批次内不得重复填报同一高中，校验拒绝 | §五｜裁决 #3 |
| R-D04 | 前批未录不影响后批资格；录取后即锁定并退出后续批次 | §三.4 |

### R-E 投档核心顺序（6 条）

| 编号 | 条文 | 出处/边界 |
|---|---|---|
| R-E01 | 第二至四批严格按批次从前到后执行 | §三.3 |
| R-E02 | 每批先处理高梯度，再处理低梯度 | §三.3 |
| R-E03 | 同一梯度内先处理第一志愿，再处理第二志愿，依次类推 | §三.3 |
| R-E04 | 每一志愿轮次内，对报考同一计划且尚未录取的合格考生，按总分降序、同分序号升序录取，直至该计划满额 | §三.3｜核心排序键 |
| R-E05 | 禁止先对每名考生依次扫描全部志愿后再处理下一人 | §三.3｜"分数优先"是错误实现 |
| R-E06 | 同分序号同一总分内唯一、数值越小优先；生成规则选做，不得两人同分且同序号 | §三.3 |

### R-F 第一批特殊规则（4 条）

| 编号 | 条文 | 出处/边界 |
|---|---|---|
| R-F01 | 仅对填报该校、在其资格名单内且达线的考生，按输入的考核排名从前到后录取至满额 | §三.2 |
| R-F02 | 达线＝总分严格大于该校计划控制线（计划控制线≥L；等于 L 或等于控制线不可录） | §三.2＋提示｜裁决 #1：以 > 为准 |
| R-F03 | 考核排名在该校内唯一；不要求实现现实综合成绩计算公式 | §三.2 |
| R-F04 | 第一批不走梯度、不做志愿轮次，直接按考核排名投档 | §三.2＋提示 |

### R-G 第二批名额隔离（3 条）

| 编号 | 条文 | 出处/边界 |

| R-G03 | 第二批计划余额按"高中＋初中"二维维护 | §四.1＋提示 |

### R-H 批次衔接与结转（8 条）

| 编号 | 条文 | 出处/边界 |

| R-H04 | 一、二批结束立即更新第三批计划余额；第四批余额不受一、二批影响 | 提示文件 |
| R-H05 | 第三、第四批余缺不互转，最终保留为未完成计划 | §三.4 |
| R-H06 | 有效计划数＝初始计划数＋转入数 | §三.4 |
| R-H07 | 必须保留结转流水（高中从一、二批流标到三批的明细） | §三.4＋提示 |
| R-H08 | 结转幂等：重复执行不得再次增加名额 | §五 |
